# Mpletech Tailwind Starter

This folder has been configured with Tailwind CSS (local build) and a CDN fallback for quick preview.

Quick start

```bash
cd "c:\Users\HomePC\Downloads\mpletech"
npm install
npm run dev
```

Open `index.html` in your browser to preview (or run a static server while `npm run dev` is running).

Build for production:

```bash
npm run build
```
